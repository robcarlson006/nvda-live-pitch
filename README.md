# NVIDIA Stock Pitch: Live-Built Presentation

| Folder | What goes here |
|---|---|
| `app/` | The live presentation app (built with Claude Code) |
| `data/bloomberg-raw/` | **Drop Bloomberg Terminal exports here** (don't edit them) |
| `data/clean/` | Cleaned data the app reads (generated) |
| `data/esg/` | ESG data: sustainability report, emissions, energy, governance, ESG scores |
| `docs/script/` | The pitch script, slide by slide, with cue phrases |
| `docs/qa-bank/` | Questions the board is likely to ask + prepared answers |
| `assets/` | Images, logos, video |
| `fallback/` | Backup static deck (PDF) in case anything fails |
| `rehearsal/` | Logs and notes from practice runs |

**Start here:** open this folder in Claude Code and paste in `KICKOFF_PROMPT.md`.
`CLAUDE.md` is the project brief that Claude Code reads automatically.
